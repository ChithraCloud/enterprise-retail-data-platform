# ☁️ Enterprise Retail Data Platform

An end-to-end Azure Data Engineering project demonstrating how retail sales data is ingested, validated, transformed, and prepared for analytics using SQL Server, Azure Data Factory, Azure SQL Database, and Power BI.

---

## 📌 Project Overview

This project simulates a real-world retail analytics platform by processing retail sales data through an ETL pipeline and preparing it for business reporting.

The project includes:

- SQL Database Design
- Data Quality Validation
- Business Analytics Queries
- SQL Views
- Stored Procedures
- Performance Optimization
- Azure Data Factory ETL Pipeline (In Progress)
- Azure SQL Database (In Progress)
- Power BI Dashboard (In Progress)
